# Notebooks

This folder is for legacy or archival notebooks. The current project keeps the active analysis notebooks at the repository root because the dashboard references `experiment_results_insights.ipynb` directly.

## Current Analysis Notebooks

- `integrated_monthly_base_eda.ipynb` - EDA on the integrated monthly source table before feature engineering.
- `calculated_features_eda.ipynb` - EDA on the calculated H3 feature table used by modeling experiments.
- `experiment_results_insights.ipynb` - directed result analysis that supports the dashboard Insights page.

## Archived Notebooks

The notebooks in `notebooks/archive/` are retained as project history. They were useful during earlier discovery/modeling phases, but they are not the canonical workflow for the current pipeline or dashboard.
